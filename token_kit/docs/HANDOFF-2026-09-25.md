## Commands and state layout

```bash
# From dev_env, expose the CLI if needed:

# Start a new task; title-only launch starts idle:
token-kit run "Fix parser" --engine codex --rollover-perc 80 --yolo

# Resume by fuzzy name, choosing if ambiguous:
token-kit continue retread
# Picker also launches the selected task:
token-kit pick retread --rollover-perc 80

# Inspect state without launching a client:
token-kit resume /absolute/task/path --agent coordinator
token-kit status /absolute/task/path
# Full histories when needed:
token-kit resume /absolute/task/path --agent coordinator --full
token-kit status /absolute/task/path --full
```

`continue` accepts paths or `--task PATH`, carries forward launch settings, and lets explicit flags override them. `--select N` supports scripted selection; `--print` previews. A live managed runner receives a cooperative stop request and verified shutdown precedes fresh recovery. This does not reattach its native UI. `resume` is an inspection command; use `continue` to restart work.

`--yolo` bypasses client permissions and Codex sandboxing. Ordinary launches use session-only guidance; persistent project installation and CodeGraph are opt-in (`--install-project`, `--codegraph`). No CodeGraph generation for this session was verified; do not assume a graph exists.

### Context and recovery

- Rollover defaults off unless configured. `--rollover-perc 80` uses the observed context window or supported Claude model defaults; it is evaluated at turn boundaries.
- `--context-window N` provides a scoped override. Unknown models/providers must not silently receive an invented capacity. Defaults in `core/context_window.py` are dated model data and may need future maintenance.
- Absolute targets such as `--rollover-tokens 500k` are capped at 80% when the window is known.
- Automatic restarts default unlimited. `--max-rollovers N` caps them; `0` disables them; `unlimited` removes the cap.
- Structured compaction recovery and verified planned handoffs can restart automatically. Unknown errors/manual interrupts are not blindly replayed. Explicit `continue` handles interrupted recovery after required process checks.
- The shared-supervisor bug confused a surviving launcher PID with the prior client still running. Matching handoff/successor evidence now permits prior-segment reconciliation without killing the supervisor. Historical Retread run `57f6ba48b6354226b633ddb9830f4527` was reconciled using this fix.
- Dead processes do not prove external publication/job success. Orphan retirement records that distinction; it is not permission to replay a release.
