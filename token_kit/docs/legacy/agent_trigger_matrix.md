# Token Kit guide

Keep the assignment in `task.md` (or an existing `in.md`), progress and next steps
in `STATE.md`, and results in `out.md` or `artifacts/`. Use ordinary text in whatever
format is useful. Optional worker folders can follow the same convention.

Save enough context for the next session before automatic rollover. The launcher
handles stopping and restarting its client. Check uncertain external outcomes
before repeating those operations. Follow user and site permissions.

Model and effort settings are explicit launch choices. Optional preferences are
plain guidance; they do not impose routing, registration, or completion protocols.

The previous routing matrix and lifecycle guide are archived in
[docs/legacy-guide.md](docs/legacy-guide.md) for old installations only.
